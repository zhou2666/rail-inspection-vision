# 无人机超低空铁轨巡检系统设计：多姿态补偿单目测距、OpenMV循迹与K230缺陷检测

本科毕业设计中使用的视觉端代码，以多姿态补偿的单目视觉测距为核心特色，同时包含 OpenMV 循迹偏差计算和 K230 铁轨表面缺陷检测。

## 核心特色：多姿态补偿的单目视觉测距

本项目的重点是面向低空铁轨巡检的**多姿态补偿视觉定高方法**。利用铁轨顶面的已知宽度建立单目测距尺度，再结合图像几何、IMU 角度与实测标定，处理摄像头横向偏移、偏航、俯仰和翻滚对距离估计的影响，为低空定高提供视觉测量量。

### 从已知轨宽建立测距尺度

基础关系为：

$$
d_0 = \frac{fW}{w_{\perp}}
$$

其中，$W$ 为铁轨顶面实际宽度，代码取 73 mm；$f$ 为标定焦距常数，代码取 290；$w_{\perp}$ 为图像中沿铁轨边缘法向测得的局部像素宽度。当前程序使用两个 ROI 分别估计近端和远端距离。

### 围绕四类扰动进行补偿

| 改进方向 | 解决的测量问题 | 当前代码的实现 |
| --- | --- | --- |
| 横向偏移补偿 | 飞行偏离轨道中心、安装偏移时，图像中的轨道位置和测量结果发生变化。 | `calculate_distance()` 计算轨道中心相对图像中心的归一化偏移，并引入经验修正因子。 |
| 边缘正交测距 | 轨道在画面中倾斜时，直接读取横向像素间距会受边缘方向影响。 | `detect_rail_edges()` 根据候选边线的平均方向，将两线中点间位移投影到法向，得到局部宽度。 |
| 俯仰角补偿 | 摄像头抬头或低头时，原有标定关系发生变化。 | 读取 JY61P 角度，以对应摄像头俯仰的轴输入分段经验模型，调整距离估计。 |
| 翻滚角补偿 | 摄像头侧倾使图像尺度与测量方向发生变化。 | 在 `pitch_roll_correction()` 中采用余弦幂形式的校正因子，指数由经验分段确定。 |

论文第 4.3.2 节将这些改进归纳为多姿态补偿模型：

$$
D = d_0\,k_{\mathrm{offset}}\,k_{\mathrm{yaw}}\,k_{\mathrm{pitch}}\,k_{\mathrm{roll}}
$$

这是论文的方法概括。当前代码把与边缘方向有关的处理融入了像素宽度计算，并未再单独乘一次偏航补偿系数。

### 结合近远端融合、滤波与实测标定

两个 ROI 均有效时，程序以 **0.7 的中端权重和 0.3 的远端权重**融合距离，再进行姿态补偿。随后应用线性标定 `D_cal = 1.06 × D - 1.18 - 31`（单位 mm），并通过指数平滑降低帧间波动；俯仰变化较明显时提高新测量值的权重，使输出更快跟随姿态变化。

这一设计将已知目标尺寸、局部图像几何、惯性测量和装置实测标定结合起来，针对低空巡检中的姿态扰动改善距离输出。标定系数对应原装置，需要随镜头、安装方式和目标尺寸重新核对。

### 论文中的实验结果

毕业论文第 6.2 节在室内模拟铁路巡检场景中报告了厘米级测量结果。根据表 6-1 至表 6-5 的实际高度与测量高度逐项计算，结果如下：

| 测试项目 | 表内测量组数 | 最大绝对误差 |
| --- | --- | --- |
| 横向偏移 | 18 | 1.2 cm |
| 旋转偏移 | 10 | 1.1 cm |
| 俯仰偏移 | 10 | 1.0 cm |
| 翻滚偏移 | 10 | 0.9 cm |
| 多维度偏移 | 10 | 3.9 cm |

其中，多维度偏移测试在实际高度 30 cm 和 50 cm 下逐步增加偏移维度；四维偏移时，测量值分别为 33.6 cm 和 53.9 cm，对应绝对误差 3.6 cm、3.9 cm。论文将视觉定高性能总结为误差不超过 ±5 cm。

上述数字来自论文记录及表内数据复算，适用于论文所述实验条件；本次整理没有重新进行硬件实验。当前仓库提供视觉测量端，飞控闭环接入与完整实飞复现还需要对应固件和接收端。

### 论文方案与当前代码版本

论文与保存的脚本并非所有细节都相同：论文横向补偿采用另一种经验函数，俯仰补偿描述为余弦项与二次经验项的组合；当前脚本分别采用归一化偏移线性因子和分段俯仰系数。论文还描述了多点边缘宽度取平均，当前脚本采用两个 ROI 各选边线对后融合距离。仓库保留实际脚本，复现时以代码为准。

## K230 缺陷检测

程序使用 CanMV 的 `PipeLine`、`AIBase`、`Ai2d`、`nncase_runtime` 等板端模块，不能直接作为普通电脑 Python 程序运行。

- 默认模型路径：`/sdcard/1best.kmodel`。
- 模型输入：320×320；摄像头图像配置：1920×1080。
- 默认 LCD 显示：800×480；代码也保留 HDMI 模式。
- 检测类别：`Cracks`、`Flakings`、`Grooves`、`Joints`、`Normal`、`Shellings`、`Spallings`、`Squats`。
- 默认置信度阈值：0.7。

将 `models/1best.kmodel` 放到板端 `/sdcard/1best.kmodel`，在提供上述模块的 CanMV 环境中打开并运行 `rail_k230.py`。原材料附带的固件文件名包含 `LCKFB`、`micropython_v1.3`、`nncase_v2.9.0`，这是历史环境线索，尚未确认具体板卡与完整版本组合。固件镜像和运行库未打包进本仓库。

当前后处理按每个类别仅保留一个高分候选框，**没有实现标准 NMS**。具体模型信息见 [模型说明](models/README.md)。

## OpenMV 测距与循迹

用支持 `pyb`、`sensor`、`image` 的 OpenMV 环境打开 `A_MV_task_ws.py`。代码配置 QQVGA（160×120），在两个 ROI 检测直线，以铁轨顶面宽度和焦距常数估算距离，并进行姿态补偿与平滑处理。

| 项目 | 代码配置 |
| --- | --- |
| 测距标定 | `W_REAL = 73` mm，`FOCAL_LEN = 290`，以及代码内的分段/线性校正系数。 |
| IMU | JY61P，UART3，9600；注释标记 P4=TX、P5=RX。 |
| 数据输出 | UART1，115200；注释标记 P1=TX、P0=RX。 |
| 启动校准 | 首次有效 IMU 角度用于零偏校准，需结合安装姿态核对。 |

输出帧为四字节：`0xFF + sign + error + distance`。`sign` 为 1 表示偏差非负、0 表示负；`error` 为偏差绝对值，上限 50；`distance` 为整数厘米，上限 90。仅在距离有效且丢失计数小于 10 时发送。

这些常数和角度轴映射来自原装置，换摄像头、安装姿态或目标尺寸后应重新标定。仓库没有飞控接收程序或飞行控制固件，不能据此直接复现整机自主飞行。
