# 开源准备记录

## 整理范围

从毕业材料建立独立代码副本，原目录未修改。仓库只包含整理后的视觉项目，不含原始毕业材料目录。

保留两份项目主程序、三份原模型、动画 HTML、YUV 转换批处理及三份数据集元数据，共 10 个原始文件，17,207,081 字节，约 16.4 MiB。每个文件均与原件逐字节核对，摘要见 [文件清单](FILE_MANIFEST.json)。目录调整没有改变源码内的板端路径或算法。

未复制的内容包括：论文、答辩 PPT、学籍与评审材料、相关论文、无人机日志和视频、2 张通用教程测试图片、通用人脸模板与动物检测示例、完整数据集、固件镜像、未下载完成的转换工具、安装程序，以及 FFmpeg EXE/DLL。

通用教程文件不是项目入口；它们的缺席不影响当前脚本的静态导入关系。脚本引用的 CanMV/OpenMV 运行库由板端环境提供，源目录中并没有完整依赖包。

## 已完成检查

- 两份 Python 主程序通过语法解析，未执行板端模块导入或无限主循环。
- 从原 OpenMV 程序提取纯计算函数，完成 7 项检查：无有效边缘、零宽度、标准测距、首次滤波、加权滤波、零姿态融合与线性距离校正。
- 原数据集 3571 对图片/标注名称匹配；逐行检查标注格式、类别索引和坐标范围。图片与标注未加入仓库。
- 按 ONNX 官方字段定义读取本地模型的输入、输出和选定元数据，未进行 ONNX 推理或 KModel 解码；提取结果见 [MODEL_METADATA.json](MODEL_METADATA.json)。
- 对拟纳入的文本文件扫描常见访问令牌、私钥及口令赋值，未发现明确凭据。三个模型未发现 Windows 用户目录路径标记；不代表已穷尽二进制元数据或全部敏感信息。

## 验证边界

没有 K230/OpenMV 板端执行、视频采集、串口接收端联调或实飞测试。主机语法检查不能验证固件 API 兼容性；纯计算检查也不是测距精度验证。模型元数据不能证明精度或导出链完整。

需要发布者继续确认板卡与固件版本、模型授权与训练来源。目录内容已分离，授权不明确的内容没有被擅自套用统一许可证。
