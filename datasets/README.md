# 数据集来源与类别差异

原材料中包含一份 Roboflow 导出的数据集，其自带元数据记录：

- 来源：[rail-uykcc / version 1](https://universe.roboflow.com/ee-6wq9x/rail-uykcc/dataset/1)。
- 许可标记：CC BY 4.0。
- 类别数量 3，类别名称为 `0`、`1`、`2`。
- 训练集 3207、验证集 204、测试集 160，共 3571 张图片；图片与标注名称一一对应。
- 本地标注逐行检查为五列 YOLO 格式，类别索引在 0–2，坐标数值在 0–1 范围内；没有检查框的语义准确性。

以上来自本地元数据与文件检查，未独立核验在线来源当前内容或完整权利链。主程序与 `1best.onnx` 是 8 类铁轨检测，不能据此认定这份 3 类数据就是该模型的训练数据，也不能自行猜测数字类别含义。

本仓库仅保留 `reference/` 中三份来源记录，不打包图片和标注。`data.original.yaml` 是原配置存档，不是可直接用于本仓库训练的配置；里面的相对路径对应原数据集布局。训练代码、类别映射和 8 类数据来源均未找到。
